## 노출 세부 규칙

- Tick 시작에 노출 상태인지 확인합니다. 이미 노출됐다면 질주가 노출을 더하거나 마지막 위험 행동 시각을 갱신하지 않습니다.
- 마지막 공격 또는 노출 진입 전 질주에서 기존 2초 대기가 지난 뒤에는 달리는 중에도 초당 15씩 감소합니다. 100에서 출발하면 다른 공격이 없을 때 대기 포함 약 8.7초가 기준입니다.
- 근접·권총을 다시 승인받으면 기존 비용을 지불하고 회복 대기도 다시 시작합니다. 피해를 받는 것 자체는 기존처럼 노출 위험 행동이 아닙니다.
- 노출이 0으로 해제된 다음 Tick부터는 질주의 일반 노출 비용이 다시 적용됩니다. 무제한 은폐 질주는 제공하지 않습니다.
- 노출 0이 된다고 기존 추격 기억을 강제로 지우지 않습니다. 시야/거리 이탈과 마지막 목격 위치 조사·수색이 여전히 필요합니다.

Inspector에서 GameSettings의 `EXPOSED_SPRINT_ALLOWS_RECOVERY`를 끄면 기존 질주 비용 규칙으로 비교할 수 있습니다. `SPRINT_SPEED`도 함께 조정할 수 있습니다. 변경 후에는 새 방을 만들고 모든 참가자가 동일한 설정/빌드를 사용합니다.

## 맵

`DeadCrowd.unity`의 `City Blockout/Escape Routes`에 네 방향의 L자 차폐물을 저장했습니다. 각 구성은 높이 2.4m, 두 벽 길이 3.4m/2.2m, 두께 0.28m이며 한쪽은 열려 다른 방향으로 나갈 수 있습니다. 기본 배치는 외곽 축의 중심에서 15.5m 지점입니다.

실제 불투명 Mesh와 BoxCollider를 함께 사용합니다. 플레이어/NPC 모두 같은 충돌·시야 차단을 적용받습니다. 별도 안전 판정·투명 은신 볼륨·순간 추격 해제는 없습니다. 본 개발 NavMesh를 새로 베이크하며 원래 시작 위치 조합과 NPC 개수는 유지합니다.

처음 한 번만 추가하는 Editor 메뉴는 `DEAD CROWD > Content > Add Escape Routes`입니다. 같은 이름의 그룹이 있으면 재생성하지 않습니다. 기존 차폐물을 편집한 뒤에는 `Rebuild Main Scene NavMesh`로 저장합니다.

## 확인 범위와 플레이 시 볼 점

컴파일·설정/Animator 정적 검사·NavMesh 생성·Windows 개발 빌드만 확인했습니다. 이탈 성공률, 선공 승률, 동선의 재미는 아직 새 버전에서 측정하지 않았습니다.

다음 플레이에서는 같은 상황에서 다음을 비교합니다.

1. 공격 후 조준을 풀고 질주했을 때 NPC와 거리가 벌어지는가.
2. 차폐물 한쪽으로 들어간 뒤 다른 쪽으로 빠졌을 때 NPC가 마지막 목격 위치를 조사하는가.
3. 추가 공격 없이 달리는 동안 노출이 감소하고 재위장할 기회가 생기는가.
4. 도주가 너무 쉬워 교전이 무의미해지는지, 혹은 여전히 사실상 탈출이 불가능한지.

이 문서는 구현 변경 기록과 다음 플레이 관찰 기준입니다. 플레이 QA 통과 보고서가 아닙니다.
