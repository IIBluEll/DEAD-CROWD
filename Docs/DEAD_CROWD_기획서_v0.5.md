# DEAD CROWD — 전투 중심 상세 기획서 v0.5

- 확정 기준일: 2026-10-28
- 문서 역할: 첫 전투 버전의 기능 범위, 규칙 및 개발·검증 기준
- 기준 자료: v0.4와 이후 사용자 논의 및 확인 답변
- 상태: 기능 범위와 핵심 규칙 확정. 수치는 첫 플레이테스트를 위한 초기 설정이며 밸런스 검증 결과가 아닙니다.

이 문서가 현재 개발 기준입니다. v0.4는 이전 기획의 기록으로 보존합니다. 이 문서를 확정했다는 것은 구현·컴파일·멀티플레이 실행·밸런스 검증을 완료했다는 뜻이 아닙니다.

## 1. 게임의 목표와 핵심 경험

DEAD CROWD는 좀비 무리에 섞여 상대 플레이어를 찾아내고, 근접 기습 또는 권총 교전으로 마지막까지 살아남는 3인칭 멀티플레이 게임입니다.

플레이어는 좀비처럼 직접 움직여 정체를 숨깁니다. 상대의 움직임을 보고 의심하더라도, 공격이나 질주를 반복하면 자신의 노출 게이지가 차오릅니다. 게이지가 가득 차면 좀비가 자신을 추격할 수 있습니다.

첫 버전에서 확인할 경험은 다음과 같습니다.

1. NPC와 비슷하게 움직이면서 상대의 수상한 행동을 관찰합니다.
2. 상대가 플레이어라고 판단하면 뒤로 접근하거나 직접 교전합니다.
3. 공격으로 상대를 제거할지, 노출 전에 물러날지 결정합니다.
4. 노출되면 시야를 끊고 좀비 추격에서 벗어납니다.
5. 마지막 생존자가 되면 승리합니다.

완벽하게 식별할 수 없는 대상을 무작위로 공격하는 것이 목표는 아닙니다. 의심할 단서는 행동에 남기되, 공격 전 이름표나 UI로 정체를 확정하지 못하게 합니다.

## 2. 확정 범위와 후속 개발

| 항목 | 첫 전투 버전의 범위 |
| --- | --- |
| 모드 | 1vs1, 4인 개인전 |
| 시점 | 3인칭 |
| 위장 | 수동 이동, 외형과 움직임을 이용한 위장 |
| 플레이어 자동 배회 | 제공하지 않음 |
| NPC | 배회, 소음 조사, 추격, 공격, 수색, 복귀 |
| 전투 | 일반 근접 공격, 후방 즉사, 권총 |
| 노출 | 행동 기반 게이지와 노출 상태 |
| 승리 | 최후의 생존자 한 명 |
| 부활 | 라운드 중 없음 |
| 라운드 종료 | 승리, 동시 전멸 무승부, 시간 초과 무승부, 세션 중단 |
| 최소 흐름 | 대기, 시작, 전투, 사망·관전, 결과, 재경기 |

### 후속 개발로 미루는 항목

- 물건 운반, 전달 장소, 목표 탈취 및 퀘스트 승리
- 탈출, 헬리콥터, 구조 요청 및 탑승 승리
- 안전 구역 축소, 서든데스 및 별도 교착 해소 장치
- 회복 아이템, 무기 획득, 장비 성장, 방어구, 헤드샷 보너스
- 팀전, 3인 모드, 라운드 도중 부활
- 붙잡기, 피격 경직, 별도 암살 연출, 회피기 및 질주 체력

권총은 이번 전투 버전에 포함합니다. 개발 순서는 근접 전투를 먼저 연결한 뒤 권총을 추가합니다. 운반·탈출을 권총과 함께 개발하는 것으로 해석하지 않습니다.

## 3. 모드와 라운드 흐름

### 3.1 모드

| 항목 | 1vs1 | 4인 개인전 |
| --- | --- | --- |
| 시작 인원 | 2명 | 4명 |
| 팀 | 없음 | 없음 |
| 승리 | 상대 사망 후 단독 생존 | 마지막 한 명으로 생존 |
| 주요 검증 | 위장, 상대 관찰, 기습과 반격 | 제삼자 개입, 교전 후 재은신, 관전 대기 |

규정 인원이 준비되지 않으면 시작하지 않습니다. 4인 모드에서 3명만으로 시작하는 규칙은 두지 않습니다. 라운드 진행 중 새 전투 참가자는 받지 않습니다.

### 3.2 시작 절차

1. 모드에 맞는 인원이 접속하고 시작 준비를 완료합니다.
2. 서버가 맵, 시작 위치와 NPC 초기 상태를 준비합니다.
3. 플레이어를 배치하고 시작 카운트다운을 진행합니다.
4. 카운트다운 종료 시 이동·전투 입력과 라운드 타이머를 함께 시작합니다.

카운트다운 중에는 이동·공격·피해·노출 게이지 누적을 진행하지 않습니다. NPC도 초기 배치를 유지합니다. 시작 전 인원이 부족해지면 대기 상태로 돌아갑니다.

### 3.3 종료

- 살아 있는 플레이어가 한 명이면 즉시 승리합니다. 좀비에게 다른 플레이어가 사망한 경우도 같습니다.
- 같은 서버 판정 단위에서 전원이 사망하면 승자 없이 무승부입니다.
- 제한 시간까지 두 명 이상 살아 있으면 시간 초과 무승부입니다. 체력이나 처치 수로 승자를 정하지 않습니다.
- 결과가 확정되면 피해, 공격, 노출 갱신과 승리 판정을 중단하고 결과 화면으로 이동합니다.
- 모든 참가자가 재경기를 준비하면 새 라운드를 시작합니다. 체력, 탄약, 노출, NPC와 시체는 초기화합니다.

첫 버전에서는 교착 상태가 얼마나 발생하는지 기록합니다. 부가 목표가 없는 테스트에서 교전이 드물었다는 사실만으로 전투 조작이나 전체 게임의 재미를 실패로 단정하지 않습니다.

### 3.4 접속 종료

초기에는 재접속 복구와 호스트 이전을 제공하지 않습니다.

- 라운드 중 일반 참가자가 연결을 잃으면 해당 플레이어는 탈락 처리합니다.
- 남은 생존자가 한 명이면 정상적인 생존 승리로 종료합니다.
- 판정을 담당하는 서버 연결이 끊겨 더 이상 경기를 진행할 수 없으면 세션 중단으로 처리합니다. 이 경우 남은 참가자에게 임의의 승리를 부여하지 않습니다.

연결 끊김을 확정하는 대기 시간은 초기 설정표를 사용하며, 짧은 지연을 즉시 탈락으로 처리하지 않습니다. 실제 네트워크 라이브러리와 서버 배치 방식은 이 문서에서 지정하지 않습니다.

## 4. 외형과 플레이어 식별

### 4.1 평상시 표현

- 플레이어와 NPC는 같은 외형 구성과 보행·피격 애니메이션을 사용합니다.
- 체형이나 외형 변형을 사용할 경우 특정 외형을 플레이어 전용으로 배정하지 않습니다.
- 이름표, 대상 체력바, 조준 색상, 상호작용 표시로 실제 플레이어를 구분하지 않습니다.
- 자기 캐릭터는 화면 구도와 본인 UI로 확인할 수 있지만, 그 표시가 다른 참가자에게 전달되지는 않습니다.
- NPC도 플레이어와 같은 체력 100으로 시작하고 같은 플레이어 공격 피해를 받습니다.

### 4.2 무기와 노출 행동

평상시에는 플레이어만 무기를 들고 다니는 모습이 보이지 않게 합니다. 근접 공격, 조준, 총격, 재장전 중에는 해당 행동에 필요한 무기와 자세를 보여줍니다.

다른 플레이어가 이런 행동을 직접 보고 정체를 알아내는 것은 허용합니다. 행동을 끝내면 평상시 자세로 돌아가지만, 이미 본 상대의 기억을 지우는 시스템은 없습니다.

발각 후 공격하거나 도망가는 행동까지 NPC와 완전히 같게 만들지는 않습니다. 공격 이후의 반응은 정체를 추정하는 단서가 될 수 있습니다.

## 5. 조작과 이동

### 5.1 조작 원칙

- 일반 이동에서 캐릭터의 몸은 이동 방향을 향합니다.
- 이동 입력이 없으면 마지막 몸 방향을 유지합니다. 카메라를 돌리는 것만으로 몸을 돌리지 않습니다.
- 카메라는 몸과 별개로 주변을 둘러볼 수 있습니다.
- 조준 중에는 몸이 조준 방향을 따릅니다. 즉시 회전하지 않고 최대 회전 속도를 적용합니다.
- 질주는 이동 속도를 높이지만 실제 질주 이동 중 노출 게이지를 계속 올립니다.
- 근접 공격은 몸 전방으로 수행하며 타깃 자동 회전·추적·돌진은 없습니다.

초기에는 자동 배회, 잠금 조준, 웅크리기, 점프, 회피, 근접 공격 콤보를 제공하지 않습니다.

### 5.2 초기 입력 배치

아래는 PC 테스트를 위한 초기 입력안입니다. 플랫폼을 확장하거나 입력 설정을 제공하는 범위를 확정한 것은 아닙니다.

| 입력 | 동작 |
| --- | --- |
| 이동 키 | 카메라의 수평 방향을 기준으로 이동 |
| 마우스 이동 | 카메라 회전 |
| 질주 키 유지 | 일반 보행 중 질주 |
| 조준 버튼 유지 | 권총 조준 |
| 공격 버튼 누름 | 비조준 상태는 근접 공격, 조준 상태는 권총 발사 |
| 재장전 키 | 권총 재장전 |

조준 버튼을 놓으면 조준을 종료합니다. 비조준 총격은 제공하지 않습니다. 권총은 공격 버튼을 누를 때 한 발씩 발사하며 누르고 있다고 연사하지 않습니다.

### 5.3 행동 조합

| 상태 | 이동 | 질주 | 다른 전투 행동 |
| --- | --- | --- | --- |
| 일반 보행 | 가능 | 가능 | 근접·조준·재장전 시작 가능 |
| 질주 | 가능 | 유지 가능 | 공격·조준·재장전 시작 시 질주 종료 |
| 근접 공격 | 감속 이동 | 불가 | 공격 주기 종료까지 추가 공격·조준·재장전 불가 |
| 권총 조준 | 감속 이동 | 불가 | 발사·재장전 가능 |
| 권총 발사 간격 중 | 조준 이동 가능 | 불가 | 발사 간격 종료까지 재발사 불가 |
| 재장전 | 보행 가능 | 불가 | 근접·조준·발사 불가 |
| 사망 | 불가 | 불가 | 불가 |

근접 공격과 재장전은 시작 후 자발적으로 취소하지 않습니다. 사망 또는 라운드 종료 시에는 중단합니다. 실행할 수 없는 입력은 무시하고, 초기에는 다음 행동의 입력 예약을 제공하지 않습니다.

NPC와 플레이어의 살아 있는 몸에는 공통된 충돌 기준을 적용합니다. 캐릭터를 자유롭게 관통하지 않으며, NPC만 통과할 수 있는 차이로 정체가 드러나지 않게 합니다.

## 6. 체력, 피격과 사망

- 플레이어와 NPC의 최대·시작 체력은 100입니다.
- 라운드 중 자연 회복, 회복 아이템과 최대 체력 증가는 없습니다.
- 방어구, 확률 치명타, 머리 부위 추가 피해와 무적 시간은 없습니다.
- 피격 반응은 시각·청각 표현으로 제공하되 이동·공격을 막는 피격 경직은 적용하지 않습니다.
- 체력 0 이하가 되면 사망하고 이후 입력과 새로운 공격 실행을 막습니다.
- 플레이어 사망 후 라운드 도중 부활하지 않습니다. NPC도 해당 라운드에서 재생성하지 않습니다.

시체는 플레이어와 NPC에 같은 유지 시간을 적용합니다. 사망 후에는 이동과 공격을 막는 몸 충돌을 해제하고, 시체를 별도 공격 대상이나 탄환 방패로 사용하지 않습니다. 시체가 생겼다는 사실은 공격이 있었다는 단서로 남습니다.

이미 시작한 공격도 실제 타격 시점 전에 사망했다면 이후 타격을 새로 발생시키지 않습니다. 단, 같은 서버 판정 단위에서 성립한 상호 공격은 사망 처리 전에 함께 결산합니다.

## 7. 근접 전투

### 7.1 피해와 모션

| 타격 방향 | 피해 | 체력 100 대상의 처치 조건 |
| --- | --- | --- |
| 정면·측면 | 60 | 2회 명중 |
| 후방 | 100 | 1회 명중 |

일반 공격과 후방 공격은 같은 버튼과 애니메이션을 사용합니다. 방향에 따라 피해만 달라지며 별도 암살 상호작용은 없습니다.

후방 공격에는 위장 상태, 상대의 전투 여부, 상대의 현재 체력 같은 추가 조건이 없습니다. 정면 교전 중에도 뒤를 잡으면 후방 피해가 적용됩니다.

### 7.2 공격의 진행

1. 실행 가능한 상태에서 입력을 받으면 공격을 시작합니다.
2. 시작 시 노출 게이지를 한 번 올리고 작은 휘두르기 소음을 발생시킵니다.
3. 선딜레이 후 한 번의 타격 판정을 수행합니다.
4. 명중한 대상에게 피해를 적용하고 명중 효과·소음을 발생시킵니다.
5. 전체 공격 주기가 끝나면 다음 행동을 허용합니다.

빗나가거나 벽에 막혀도 공격 주기와 노출 증가를 취소하지 않습니다. 명중에 성공했다고 노출 게이지를 한 번 더 올리지 않습니다.

### 7.3 타격 대상과 차단

- 캐릭터 몸 전방의 좁은 공격 범위에서 타격 궤적상 처음 닿는 살아 있는 캐릭터 한 명에게만 피해를 줍니다.
- 같은 공격으로 여러 NPC나 플레이어를 함께 타격하지 않습니다.
- 한 공격으로 같은 대상에게 여러 번 피해를 주지 않습니다.
- 벽과 지형이 먼저 가로막으면 그 뒤의 대상을 공격하지 못합니다.
- 앞에 NPC가 있으면 뒤의 플레이어만 골라 관통해 때리지 않습니다.
- 플레이어와 NPC를 구분해서 우선 타격하는 보정은 없습니다.

사거리와 전방 범위는 타격 순간의 공격자 몸 방향으로 판단합니다. 타격 거리 밖에서 시작했더라도 타격 순간에 유효 범위에 들어와야 명중합니다.

### 7.4 후방 판정

후방 여부는 실제 타격 시점에 대상 몸의 수평 전방과 대상에서 공격자로 향하는 수평 방향을 기준으로 판단합니다. 카메라 방향이나 공격 버튼을 누른 시점의 방향을 사용하지 않습니다.

대상 정후방에서 좌우 각 50도 이내면 후방 공격입니다. 경계값은 후방 범위에 포함합니다. 타격 전에 대상이 돌아서 범위를 벗어나면 일반 피해를 줍니다.

공격자의 자동 회전·돌진은 없으며, 공격 중 수동 회전은 일반 이동보다 느리게 제한합니다. NPC에도 같은 방향 판정을 적용합니다.

## 8. 권총 전투

### 8.1 장비와 발사

- 모든 플레이어가 동일한 권총과 탄약으로 시작합니다. 무기 획득이나 장비 차이는 없습니다.
- 조준 상태에서만 발사할 수 있습니다.
- 유효한 발사 한 번에 탄약 한 발을 소비하고 노출과 총성을 한 번 발생시킵니다.
- 탄약이 없거나 발사 간격이 끝나지 않은 입력은 발사로 처리하지 않습니다.
- 빈 탄창 입력은 피해·총성·발사 노출을 발생시키지 않습니다. 자동 재장전은 하지 않습니다.
- 발사 시점에 명중을 판정하는 방식을 사용합니다. 이동하는 물리 탄환과 관통은 초기 범위에 넣지 않습니다.

### 8.2 조준과 차단

카메라 조준점으로 목표 방향을 정하되, 총구에서 그 방향으로 나가는 경로가 벽이나 캐릭터에 막히면 먼저 맞은 대상에서 멈춥니다. 카메라만 벽 너머를 보고 있다고 총구 앞의 벽을 통과할 수는 없습니다.

NPC도 탄환을 막고 동일한 피해를 받습니다. 아군 개념과 대상 종류에 따른 관통 예외는 없습니다. 사거리 내 피해는 55로 같고 거리 감소·확률 탄퍼짐·머리 추가 피해는 첫 버전에 넣지 않습니다.

### 8.3 탄약과 재장전

탄창과 예비 탄약은 유한합니다. 재장전 완료 시 예비 탄약에서 필요한 만큼 채우고, 남아 있던 탄창의 탄약을 버리지는 않습니다. 재장전 시작 시 조준을 종료합니다.

탄창이 가득 차 있거나 예비 탄약이 없으면 재장전을 시작하지 않습니다. 사망 등으로 중단된 재장전은 완료된 것으로 처리하지 않습니다. 탄약 보급은 없으며 소진 후에도 근접 공격은 가능합니다.

### 8.4 조준과 노출의 확정 규칙

사용자 확인에 따라 **조준만 유지하는 행동은 노출 게이지를 올리지 않습니다.** 조준 자체는 게이지 감소 대기 시간을 초기화하지도 않습니다.

다른 플레이어가 조준 자세를 보고 정체를 알아내는 것은 가능합니다. 노출 상태가 아닌 플레이어를 좀비가 조준 자세만 보고 즉시 추격하는 별도 예외는 두지 않습니다.

## 9. 노출 게이지

### 9.1 공통 원칙

노출 게이지는 플레이어별 0~100의 수치입니다. 공격 대상이 NPC인지 플레이어인지에 따라 증가량이나 좀비 반응을 바꾸지 않습니다. 기존 오인 공격 횟수와 별도 경계 단계는 사용하지 않습니다.

노출 게이지는 다른 플레이어가 정체를 아는지를 나타내는 수치가 아닙니다. 좀비의 신규 추격 대상이 될 수 있는 상태를 관리합니다.

### 9.2 행동별 변화

| 행동 | 게이지 변화 | 소음·관찰과의 관계 |
| --- | --- | --- |
| 걷기·정지·카메라 회전 | 증가 없음 | 평상시 좀비가 추격하지 않음 |
| 조준 유지 | 증가 없음 | 다른 플레이어에게는 강한 식별 단서 |
| 재장전 | 증가 없음 | 자세로 정체가 드러날 수 있음 |
| 근접 공격 시작 | 공격당 고정량 증가 | 빗나가도 동일, 작은 소음 발생 |
| 실제 질주 이동 | 지속 시간에 비례해 증가 | 게이지가 가득 차면 직접 목격한 좀비가 추격 가능 |
| 유효한 권총 발사 | 발사당 큰 폭으로 증가 | 넓은 범위의 소음 발생 |
| 피해를 받음 | 피격 자체로는 증가 없음 | 별도의 강제 노출을 발생시키지 않음 |

공격 입력이 거부된 경우는 게이지를 올리지 않습니다. 질주 키만 누르고 제자리에 있으면 질주 누적을 발생시키지 않습니다.

### 9.3 게이지와 노출 상태의 구분

| 상황 | 상태 |
| --- | --- |
| 노출 전, 게이지 0~99 | 신규 좀비 추격의 대상이 되지 않음 |
| 처음 100 도달 | 노출 상태 진입 |
| 노출 후 99~1로 감소 | 노출 상태 유지 |
| 노출 후 0 도달 | 노출 상태 해제 |

100에서 99로 내려갔다고 즉시 안전해지는 구조는 사용하지 않습니다. 게이지가 100에 도달하지 않았더라도 위험 행동을 멈추면 감소할 수 있습니다.

### 9.4 증가와 감소

- 근접 공격, 발사, 실제 질주는 게이지 감소 대기 시간을 갱신합니다.
- 위험 행동을 멈추고 대기 시간이 지나면 일정 속도로 감소합니다.
- 위험 행동을 지속하거나 다시 시작하면 감소를 멈추고 해당 증가를 적용합니다.
- 게이지는 100을 넘지 않습니다. 100에서 계속 위험 행동을 해도 초과 수치를 저장하지 않지만 감소 대기는 계속 갱신합니다.
- 같은 갱신 시점에 위험 행동이 있으면 증가와 대기 갱신을 우선하고 감소를 적용하지 않습니다.

초기 설정 기준으로 근접 공격 세 번은 100에 도달합니다. 다만 공격 사이에 충분히 기다리면 감소할 수 있으므로 항상 세 번째 공격에서 노출되는 것은 아닙니다.

### 9.5 노출 해제와 기존 추격

게이지가 0이 되는 것은 새로운 좀비가 추격을 시작하는 조건을 해제합니다. 이미 자신을 쫓던 좀비의 기억을 즉시 지우지는 않습니다.

기존 추격자는 시야 상실 후 마지막 목격 위치를 수색합니다. 그 수색이 끝나기 전에 원래 대상을 다시 보면 게이지가 0이어도 추격을 재개할 수 있습니다. 수색 종료 후에는 기억을 해제하고 다시 공통 노출 조건을 따릅니다.

이 때문에 게이지를 낮추는 것과 추격자의 시야·수색에서 벗어나는 것이 모두 중요합니다.

## 10. 좀비 AI와 인지

### 10.1 행동 상태

| 상태 | 행동 | 주요 전환 |
| --- | --- | --- |
| 배회·대기 | 주변 이동과 정지 반복 | 소음 인지 시 조사, 노출 대상 발견 시 추격 |
| 조사 | 소음이 발생한 위치로 이동해 주변 확인 | 노출 대상 발견 시 추격, 조사 종료 시 배회 |
| 추격 | 직접 확인한 대상을 따라감 | 공격 거리면 공격, 시야 상실 시 마지막 위치 수색 |
| 공격 | 근거리 공격 수행 | 대상이 멀어지면 추격, 시야를 잃으면 수색 |
| 수색 | 마지막 목격 위치와 주변 확인 | 기억한 대상 재발견 시 추격, 수색 종료 시 배회 |

### 10.2 시야와 신규 추격

좀비는 시야 거리, 전방 시야각, 벽·지형에 의한 차단을 검사합니다. 신규 추격에는 해당 좀비가 플레이어를 직접 보고 있으며 그 플레이어가 노출 상태라는 조건이 모두 필요합니다.

노출 100이 됐다는 이유로 맵 전체 좀비가 위치를 알지는 못합니다. 좀비끼리 원거리로 대상 정보를 공유하지 않습니다. 첫 버전에서는 다른 캐릭터의 몸을 완전한 시야 차단물로 사용하지 않고 벽·지형으로 시야를 끊습니다.

여러 신규 노출 대상을 동시에 발견하면 가까운 대상을 선택합니다. 추격 중에는 기존 대상을 우선 유지하며, 주변에 다른 플레이어가 왔다고 매번 바꾸지 않습니다. 기존 대상이 사망하면 현재 직접 보이는 다른 노출 대상을 찾고 없으면 배회로 복귀합니다.

### 10.3 소음 조사

소음은 공격자를 자동 식별하는 정보가 아니라 발생 위치 정보입니다. 범위 안의 좀비가 해당 위치를 조사하며, 벽 너머의 소음도 들을 수 있습니다. 초기에는 벽 재질별 감쇠 계산을 사용하지 않습니다.

노출 게이지가 낮아도 공격 소리에 따른 조사는 발생합니다. 조사 도중 플레이어를 봤더라도 노출 상태가 아니고 기존에 추격하던 대상도 아니면 새 추격을 시작하지 않습니다.

추격·공격 중인 좀비는 다른 소음 때문에 대상을 버리지 않습니다. 배회·조사 중에 새 소음을 들으면 최근 소음 위치를 조사 대상으로 갱신합니다.

### 10.4 피격 NPC

피격한 NPC도 시각적 반응은 보이지만, 피해를 받았다는 이유만으로 노출 규칙을 무시하고 반격하지 않습니다. 살아 있다면 현재 노출 조건과 기존 추격 기억에 따라 행동합니다.

공격자가 노출된 경우에도 일반적인 직접 시야 확인을 거쳐 추격합니다. 맞았다는 이유로 벽 너머 공격자의 현재 위치를 계속 추적하지 않습니다.

### 10.5 추격, 공격과 수색

- 속도 관계는 플레이어 보행 < 좀비 추격 < 플레이어 질주로 설정합니다.
- 좀비 공격에는 선딜레이가 있고 타격 시점에 거리와 차단을 다시 확인합니다.
- 공격 하나는 추격 대상 한 명에게만 피해를 주며 플레이어를 붙잡거나 경직시키지 않습니다.
- 여러 좀비의 독립적인 공격은 각각 적용될 수 있습니다.
- 시야를 잃으면 대상의 새 위치를 받아 따라가지 않고 마지막으로 본 위치를 확인합니다.
- 마지막 목격 위치 도착 후 정해진 시간 동안 수색하고, 발견하지 못하면 기억을 지우고 복귀합니다.
- 경로가 막혀 조사·수색 위치에 도달하지 못하면 이동 시도 제한 시간 후 현재 도달 가능한 위치에서 확인을 마치고 복귀합니다.

노출 상태가 계속 유지되면 새로운 좀비에게 다시 발견될 수 있습니다. 반대로 게이지가 낮아졌어도 기존 추격자에게 보이는 동안에는 재은신이 완료된 것이 아닙니다.

## 11. 맵과 시작 배치

첫 버전은 작은 맵 하나를 사용합니다. 절차적 맵 생성은 포함하지 않습니다.

### 11.1 필요한 공간

- 상대의 움직임을 관찰하며 NPC에 섞일 수 있는 열린 공간
- 시야를 끊을 수 있는 건물 모서리와 연결 통로
- 추격자와 거리를 벌릴 수 있는 둘 이상의 이동 경로
- 플레이어와 NPC가 과도하게 끼지 않는 통로 폭

일방적인 막다른 길이나 시작 위치에서 다른 참가자를 즉시 공격할 수 있는 배치는 제외합니다. 모든 시작 위치가 완전히 같은 모양일 필요는 없지만 이동 기회와 위장 환경을 비교합니다.

### 11.2 배치 원칙

- 플레이어 시작점과 NPC 초기 배치는 검토한 후보 조합에서 선택합니다.
- 플레이어끼리 겹치거나 직접 마주 보는 위치에서 시작하지 않습니다.
- 각 시작점 주변에 NPC 무리와 시야 차단 경로를 제공합니다.
- 플레이어에게만 비어 있는 장소나 전용 출현 효과를 배정하지 않습니다.
- NPC의 초기 수뿐 아니라 실제 플레이 경로의 밀도를 확인합니다.

NPC가 처치되면 해당 라운드의 위장 공간이 줄어듭니다. 자동 보충으로 이를 감추지 않고, 무작위 공격과 NPC 감소가 게임에 미치는 영향을 기록합니다.

## 12. UI, 소리와 관전

### 12.1 본인에게 표시하는 정보

- 현재 체력
- 노출 게이지와 노출 상태 경고
- 탄창·예비 탄약과 재장전 진행
- 남은 시간과 살아 있는 플레이어 수
- 피격, 사망, 결과 및 재경기 준비 상태

노출 경고는 게이지가 감소 중이어도 노출 상태가 유지되는 동안 표시합니다. 노출 0이 곧 기존 좀비 추격 종료라는 뜻으로 안내하지 않습니다.

### 12.2 타격 피드백

공격 명중과 빗나감을 구분할 수 있는 소리·효과를 제공합니다. NPC와 실제 플레이어에게 공통된 명중 표현을 사용하고, 대상 종류에 따른 색상·소리 차이를 두지 않습니다.

상대 체력 수치, 피해 숫자, 이름표와 플레이어 전용 명중 마커는 표시하지 않습니다. 본인이 피해를 받았다는 사실은 체력 변화와 화면·소리로 전달합니다.

발사 소리와 시각적 총격 표현은 다른 플레이어가 방향을 추정할 단서로 사용합니다. 노출 게이지 수치를 상대에게 공개하지 않습니다.

### 12.3 사망·관전과 결과

4인전에서 사망한 플레이어는 생존자 시점을 따라 관전할 수 있습니다. 생존자의 조작에는 개입하지 못하며, 관전 전용 정보는 생존자에게 전달하지 않습니다. 관전 시점에서도 월드 안의 NPC·플레이어 전용 이름표를 추가하지 않습니다.

본인 사망 시 원인을 일반 근접·후방 근접·권총·좀비·연결 종료로 구분합니다. 결과 화면에는 승자 또는 무승부·세션 중단 사유를 표시합니다. 전투 중 전체 참가자에게 공격자의 이름과 위치를 알려주는 처치 알림은 제공하지 않습니다.

생존 인원은 공개하지만 생존자의 실시간 위치나 NPC와 구분되는 목록은 제공하지 않습니다. 별도 음성·채팅 기능은 첫 버전에 넣지 않습니다.

## 14. 멀티플레이와 판정 원칙

### 14.1 권한

서버 또는 권한을 가진 호스트가 다음을 최종 판정합니다.

- 이동·행동 상태의 유효성
- 공격 시작, 타격 시점, 사거리, 장애물, 후방 여부와 피해
- 탄약 소비, 재장전 완료와 발사 간격
- 노출 증가·감소와 노출 상태 전환
- NPC의 감각, 추격 대상, 공격과 수색
- 체력, 사망, 생존 인원, 타이머와 라운드 결과

클라이언트는 자신의 화면에서 후방으로 보였다는 이유만으로 즉사를 확정하지 않습니다. 초기에는 서버 타격 시점의 위치와 회전으로 판정하고, 실제 지연 환경의 불일치를 기록합니다. 위치 이력 보정은 원인과 빈도를 확인한 뒤 검토합니다.

### 14.2 같은 시점의 공격과 종료

같은 서버 판정 단위에서는 시작 시점에 살아 있고 실행 조건을 충족한 공격의 명중을 모은 뒤 피해와 사망을 결산합니다. 한쪽 공격을 먼저 처리했다는 이유만으로 같은 시점의 상대 공격을 임의로 지우지 않습니다.

결산 후 생존 인원을 기준으로 승리 또는 전멸 무승부를 한 번만 확정합니다. 이전 판정 단위에서 이미 사망한 플레이어의 후속 공격은 실행하지 않습니다.

제한 시간 경계에서는 종료 시점까지 유효하게 성립한 피해를 먼저 결산합니다. 그 결과 한 명이면 승리, 전원이 사망했으면 전멸 무승부, 두 명 이상이면 시간 초과 무승부입니다. 클라이언트가 임의의 과거 시각을 보내 종료 후 공격을 추가할 수는 없습니다.

상세한 네트워크 전송 방식이나 라이브러리 선정은 구현 설계에서 다룹니다. 특정 API나 네트워크 프레임워크를 사용 중이라고 가정하지 않습니다.

## 15. 개발 순서

아래 단계는 구현 계획입니다. 체크 완료나 실행 검증 결과가 아닙니다.

### 1단계: 조작과 근접 교전

- 최소 맵과 플레이어 이동·카메라·몸 회전
- 일반·후방 근접 공격과 단일 대상 타격
- 체력, 피해, 사망과 동시 공격 처리
- NPC와 공통 외형·피격 표현
- 기본 멀티플레이 동기화와 서버 판정

이 단계는 공격 조작과 판정의 성립을 확인합니다. NPC 행동이나 목표가 충분하지 않은 상태의 교전 빈도로 전체 재미를 판단하지 않습니다.

### 2단계: 위장·노출·좀비 반응

- NPC 배회와 시야·소음 조사
- 행동 기반 노출 게이지와 노출 유지·해제
- 추격·공격·마지막 위치 수색·복귀
- 1vs1 및 4인 개인전의 시작 배치와 생존 승리

이 단계에서는 상대를 의심하는 이유, 공격 후 도주, 재은신 가능 여부와 무작위 NPC 공격의 이득을 확인합니다.

### 3단계: 권총과 한 판의 완성

- 조준·발사·차단·탄약·재장전
- 총성과 발사 노출
- HUD, 결과, 관전과 재경기
- 시간 초과, 접속 종료와 세션 중단 처리
- 두 모드의 이동·교전·종료 흐름 통합 검증

이 단계까지가 이번 첫 전투 버전입니다. 운반·탈출과 안전 구역을 완료 조건에 넣지 않습니다.

## 16. 검증 항목과 기록

### 16.1 규칙 검증

| 확인 상황 | 기대 결과 |

문서 확인, 코드 수준 검증, Unity 컴파일, 실제 네트워크 플레이를 구분해 보고합니다. 한 종류의 검증을 다른 종류의 완료 근거로 대신하지 않습니다.

### 16.2 플레이 관찰

- 무엇을 보고 상대가 사람이라고 의심했는지
- 수동 이동으로 NPC를 흉내 낼 수 있었는지와 조작의 번거로움
- NPC를 공격하고 기다리는 반복 전략의 이득
- 후방 즉사를 당한 이유와 공격 실패를 납득했는지
- 권총과 근접 공격을 각각 선택한 이유
- 노출 전후 행동 변화와 추격에서 실제로 탈출한 경로
- 피격·저체력 이후 교전 회피가 얼마나 늘어나는지
- NPC 처치로 무리 밀도가 줄어든 이후의 플레이 변화
- 첫 교전까지 걸린 시간, 라운드 종료 시간과 시간 초과 빈도
- 4인전의 제삼자 개입과 조기 사망 후 대기 시간
- 실제 지연 환경에서 공격자·피격자의 판정 체감 차이

관찰 없이 수치가 적절하다고 확정하지 않습니다. 현재 범위에서 발생한 교착은 기록하고, 운반·탈출 등 후속 목표의 필요성을 판단할 자료로 남깁니다.

## 17. 변경 관리

### 확정한 핵심 규칙

- 1vs1과 4인 개인전, 수동 위장, 최후 생존 승리
- 동일 모션의 일반 근접 공격과 후방 즉사
- 한 번의 근접 공격은 한 대상만 타격
- 근접 공격 중 감속·회전 제한, 자동 추적과 자발적 취소 없음
- 권총 포함, NPC와 벽이 공격·탄환을 차단
- 대상 종류와 무관한 행동 기반 노출 게이지
- 조준 자체는 게이지 증가 없음
- 100에서 노출되고 0까지 노출 유지, 기존 추격 기억은 별도
- 회복·부활·피격 경직 없음, 사망·관전·재경기 제공
- 운반·탈출·안전 구역은 현재 개발 범위 밖

### 테스트로 조정할 값

피해량, 사거리·각도, 이동·회전 속도, 선딜레이·공격 주기, 탄약·재장전 시간, 노출 증가·감소량, 감각 범위, NPC 수, 맵 규모, 조사·수색 시간과 제한 시간은 초기 설정값입니다.

수치를 조정하더라도 후방 명중 시 즉사, 플레이어와 NPC의 공통 타격 규칙, 노출 진입 후 해제까지의 상태 유지라는 핵심 규칙은 보존합니다. 예를 들어 체력을 바꿀 경우 후방 피해도 즉사 조건을 충족하도록 함께 검토하며, 후방 공격을 즉사가 아닌 공격으로 바꾸는 것은 단순 수치 조정으로 처리하지 않습니다.

수치 변경과 기능·규칙 변경을 구분하고, 변경 시 이 문서에 이유와 검증 범위를 남깁니다. 이전 버전 문서나 대화의 폐기된 규칙을 현재 규칙과 혼용하지 않습니다.
