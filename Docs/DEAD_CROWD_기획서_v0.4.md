# DEAD CROWD — 통합 기획 v0.4

- 작성일: 2026-10-27
- 기준 자료: 사용자가 제공한 통합 기획 v0.3 및 후속 논의
- 문서 상태: 합의된 방향을 반영한 기획안. 세부 수치는 플레이테스트 전 초안입니다.

## 1. 게임 개요

DEAD CROWD는 좀비 무리에 섞여 상대 플레이어를 찾아내고, 기습하거나 운반 목표를 달성해 승리하는 3인칭 멀티플레이 게임입니다.

플레이어는 직접 좀비처럼 움직여 정체를 숨깁니다. 상대를 찾았더라도 공격하면 주변 좀비와 다른 플레이어에게 행동이 드러날 수 있습니다. 숨는 것뿐 아니라 언제 이동하고, 언제 공격하고, 언제 목표를 수행할지 판단하는 것이 핵심입니다.

| 항목 | 기획 방향 |
| --- | --- |
| 우선 지원 모드 | 1vs1, 4인 개인전 |
| 시점 | 3인칭 |
| NPC 좀비 | 20~30마리를 기준으로 테스트하되, 모드와 맵에 따라 조정 |
| 플레이어 자동 배회 | 사용하지 않음 |
| 전투 | 근접 공격 + 권총 |
| 승리 조건 | 최후의 생존 또는 운반 퀘스트 완료 |
| 목표 라운드 길이 | 약 6분, 검증용 기준 |

### v0.3에서 달라지는 점

| 항목 | v0.4 변경 내용 |
| --- | --- |
| 위장 조작 | 플레이어 자동 배회를 제거하고 수동 이동으로 위장 |
| 오인 공격 | NPC를 잘못 공격하면 경계가 누적되며, 초기에는 조사하고 반복하면 추격 |
| 경계 회복 | 충분히 숨어 지내면 경계가 서서히 감소 |
| 목표 경쟁 | 헬리콥터 호출·탑승을 제거하고 물건 운반 완료 승리로 대체 |
| 모드 | 연속적인 2~4명 지원 대신 1vs1과 4인 개인전을 우선 검증 |
| 개발 범위 | 위장과 근접 전투부터 확인하고 권총·운반을 단계적으로 추가 |

안전 구역 축소는 삭제를 확정한 것이 아닙니다. 운반 목표만으로 충분한 이동과 교전이 발생하는지 확인한 뒤 도입 여부를 판단합니다.

## 2. 핵심 플레이 흐름

1. 좀비들의 움직임을 관찰하며 직접 이동합니다.
2. 이동 경로, 멈추는 시점, 방향 전환, 목표에 대한 반응으로 상대를 의심합니다.
3. 상대 뒤로 접근하거나 직접 교전할 기회를 만듭니다.
4. 공격으로 주변의 경계가 높아지면 추격을 피하고 다시 무리에 섞입니다.
5. 상대를 모두 제거하거나, 운반 물건을 확보해 목적지에 전달하면 승리합니다.

목표하는 경험은 완벽하게 구별할 수 없는 상태에서 무작위로 공격하는 것이 아닙니다. 행동으로 의심할 수 있지만, 확신을 얻거나 행동으로 옮기려면 위험을 감수하는 상황입니다.

## 3. 위장과 수동 이동

### 외형과 정보

사람과 NPC 좀비는 평상시 외형만으로 정체를 확정할 수 없어야 합니다. 타격 전 이름표, 조준 표시, 체력 표시, 전용 상호작용 UI로 실제 플레이어를 구분하지 않습니다.

위장 지속시간은 없습니다. 다만 평상시 위장이 가능하다는 것이 이미 자신을 추격하는 좀비가 즉시 공격을 멈춘다는 뜻은 아닙니다.

### 자동 배회 제거

플레이어가 NPC처럼 자동으로 움직이는 기능은 제공하지 않습니다. 플레이어는 직접 걷고, 멈추고, 방향을 바꾸며 좀비의 행동을 흉내 냅니다. NPC의 자체 배회는 유지합니다.

| 행동 | 다른 플레이어가 얻을 수 있는 단서 |
| --- | --- |
| 걷기, 정지, 방향 전환 | 이동 패턴에 따라 의심할 수 있으나 행동 하나로 정체를 확정하지 않음 |
| 특정 대상을 계속 따라감 | 추적하거나 뒤를 잡으려는 행동으로 의심 가능 |
| 목표 물건이나 목적지를 향해 이동 | 목표 수행 중인 플레이어로 의심 가능 |
| 질주, 무기 조준, 공격 | 인간의 행동이라는 강한 단서 |

플레이어의 보행 속도와 몸의 회전 방식은 NPC를 흉내 낼 수 있는 범위여야 합니다. 구체적인 이동·회전 수치는 아직 확정하지 않습니다.

### 카메라와 회전: 구현 전 결정 필요

후방 판정은 카메라가 아니라 대상 캐릭터의 몸 방향을 기준으로 합니다. 다만 다음 사항은 아직 미정입니다.

- 카메라를 돌려도 캐릭터가 같은 방향을 유지하는지
- 보행·조준 중 몸 방향을 무엇으로 결정하는지
- 제자리 회전과 공격 중 회전 속도를 얼마나 허용하는지

자유로운 카메라 회전이 기습 대응에 미치는 영향과, 몸 회전이 정체를 너무 쉽게 드러내는지 함께 검증해야 합니다. 후방 판정 각도만 조절해 해결된 것으로 보지 않습니다.

## 4. 전투 규칙

### 체력과 피해량

플레이어 체력은 100입니다. 헤드샷, 방어구, 치명타 확률은 초기 범위에 포함하지 않습니다.

아래 수치는 v0.3을 유지하는 테스트 시작값입니다. 밸런스가 검증된 값은 아닙니다.

| 공격 유형 | 피해량 | 체력 100 대상의 처치 조건 |
| --- | --- | --- |
| 정면 근접 공격 | 60 | 2회 명중 |
| 측면 근접 공격 | 60 | 2회 명중 |
| 후방 근접 공격 | 100 | 1회 명중 |
| 권총 | 55 | 2발 명중 |

일반 근접 공격과 후방 공격은 같은 버튼과 애니메이션을 사용하며, 명중 시 상대 방향에 따라 피해량을 결정합니다. 별도 암살 연출은 추가하지 않습니다.

### 후방 공격 판정

| 항목 | 테스트 시작값 또는 원칙 |
| --- | --- |
| 근접 사거리 | 1.3m |
| 후방 범위 | 대상 정후방 기준 좌우 각 50도, 총 100도 |
| 공격 선딜레이 | 0.3초 |
| 전체 공격 주기 | 0.85초 |
| 판정 시점 | 공격 버튼 입력 시점이 아닌 실제 타격 시점 |
| 명중 조건 | 사거리, 방향, 장애물 검사 충족 |
| 자동 보정 | 타격 순간 자동 회전이나 돌진 없음 |

위장 상태, 대상의 전투 여부, 대상의 남은 체력은 후방 공격의 추가 조건으로 사용하지 않습니다. 교전 중에도 뒤를 잡으면 즉사가 가능합니다.

타격 직전에 대상이 몸을 돌려 후방 범위를 벗어나면 일반 근접 피해가 적용됩니다.

### NPC에도 같은 타격 규칙 적용

NPC 좀비도 후방 근접 공격에 즉사합니다. 공격 버튼이나 명중 전 UI가 실제 플레이어만 특별하게 취급해서는 안 됩니다.

초기에는 체력과 피격 반응 차이가 손쉬운 식별 수단이 되지 않도록 맞추는 안을 제안합니다. NPC의 세부 체력과 피격 반응은 검증 항목으로 남깁니다.

권총의 탄약 수, 재장전, 발사 간격과 명중 방식은 아직 미정이며, 권총을 추가하는 단계에서 정합니다.

## 5. 오인 공격과 경계 누적

### 기본 원칙

NPC 좀비를 잘못 근접 공격했다고 첫 실수부터 즉시 집중 추격을 받지는 않습니다. 대신 주변 좀비가 공격 위치를 조사하고, 짧은 시간 안에 오인 공격을 반복하면 추격 위험이 커집니다.

첫 공격에도 조사와 시체라는 흔적이 남습니다. 처음 몇 번을 아무 위험 없이 정체 확인에 쓸 수 있는 구조는 피합니다.

### 경계 단계: 검증용 초안

2~3회 반복 후 추격한다는 방향을 기준으로, 첫 테스트에서는 3단계를 사용합니다. 아래는 확정된 밸런스가 아닙니다.

| 경계 단계 | 오인 공격 누적 예시 | 주변 좀비 반응 |
| --- | --- | --- |
| 0 | 최근 오인 공격 없음 | 평상시 배회 |
| 1 | NPC에 첫 근접 공격 명중 | 인지한 좀비가 공격 위치 조사 |
| 2 | 경계가 남아 있는 동안 두 번째 명중 | 조사 상태 유지, 반복 공격 흔적이 남음 |
| 3 | 경계가 남아 있는 동안 세 번째 명중 | 해당 공격자를 직접 목격한 주변 좀비가 추격 |

오인 공격은 NPC에게 근접 공격이 명중한 경우를 뜻합니다. 공격 한 번으로 여러 NPC를 맞히더라도 경계는 한 단계만 올리는 안으로 시작합니다. 빗나간 공격은 경계를 올리지 않되, 가까운 공격 소리에 따른 조사는 발생할 수 있습니다.

처치 여부와 관계없이 명중을 기준으로 하므로, 한 NPC를 정면에서 두 번 공격하면 두 번 누적됩니다.

### 인지 범위

- 소리를 들은 좀비는 소음 위치를 조사합니다.
- 경계가 높아도 공격자를 직접 보지 못한 좀비가 위치를 자동으로 아는 것은 아닙니다.
- 추격 조건을 충족한 공격자를 직접 본 좀비만 추격을 시작합니다.
- 좀비 사이의 원거리 정보 공유와 맵 전체 동시 추격은 초기 범위에 넣지 않습니다.

경계는 플레이어별로 관리하되, 수치를 상대에게 공개하거나 오인 명중 여부를 알려주는 UI는 제공하지 않습니다. 좀비의 반응 차이만으로 상대 정체를 쉽게 확정할 수 있는지도 검증합니다.

### 경계 감소와 재은신

공격 등 경계를 유지시키는 행동을 멈추고 충분한 시간이 지나면 경계가 서서히 감소합니다. 정확한 대기 시간과 감소 속도는 미정입니다.

이미 추격 중인 좀비는 경계 수치가 낮아졌다는 이유만으로 즉시 복귀하지 않습니다. 시야를 끊고, 마지막 목격 위치의 수색을 벗어나야 다시 무리에 섞일 수 있습니다.

### 다른 노출 행동과의 관계

오인 공격 완화는 NPC 대상 근접 공격에 적용합니다. 질주나 총격까지 세 번 허용하는 규칙으로 확대하지 않습니다.

| 플레이어 행동 | 좀비 반응 |
| --- | --- |
| 걷기, 정지, 일반적인 방향 전환 | 평상시에는 무시 |
| 질주 | 직접 목격하면 추격 |
| 무기 조준 | 가까운 좀비가 직접 목격하면 추격 |
| NPC 대상 근접 공격 | 소음 조사 및 오인 공격 경계 누적 |
| 실제 플레이어 대상 근접 공격 | 소음 조사, 공격 장면을 직접 목격하면 추격하는 기존안 유지 |
| 총기 발사 | 광범위 소음 조사, 발사자를 직접 목격하면 추격 |
| 물건 소지 | 소지 자체만으로 좀비 추격을 발생시키지 않는 안으로 시작 |

공격 대상에 따른 좀비 반응 차이가 원치 않는 식별 수단이 된다면, 근접 공격 전체에 공통 경계 규칙을 적용하는 대안을 검토합니다. 이 부분은 실제 플레이 후 결정합니다.

## 6. 승리 조건

### A. 최후의 생존

살아 있는 플레이어가 마지막 한 명이 되면 즉시 승리합니다. 다른 플레이어가 좀비에게 사망한 경우도 포함합니다.

1vs1은 상대가 사망하면 종료됩니다. 4인 개인전은 마지막 생존자가 승리하며, 팀전은 포함하지 않습니다.

### B. 운반 퀘스트 완료

맵에 등장하는 공용 물건 하나를 확보하고 지정된 목적지로 운반하면 승리합니다. 운반 완료는 전투 보상이 아니라 별도의 승리 조건입니다.

헬리콥터, 무전기 호출, 도착 대기, 탑승 상호작용은 이번 기획에서 사용하지 않습니다.

## 7. 운반 퀘스트

다음 세부 절차는 합의된 운반 방향을 구체화한 첫 테스트용 제안입니다.

### 물건과 목적지 생성

- 물건 위치와 목적지는 이동 가능한 후보 지점 중 무작위로 선정합니다.
- 두 지점이 지나치게 가깝거나 경로가 막힌 조합은 제외합니다.
- 목적지는 최소 두 방향에서 접근할 수 있는 위치를 우선합니다.
- 초기에는 공용 물건 하나만 사용하며, 개인별 퀘스트나 다중 물건은 추가하지 않습니다.

### 진행 과정

1. **목표 활성화:** 라운드 중 물건과 목적지가 활성화됩니다. 정확한 활성화 시점은 테스트로 정합니다.
2. **목표 공개:** 초기 물건 위치와 목적지를 모든 생존자에게 알립니다.
3. **물건 획득:** 물건에 접근해 상호작용하면 소지합니다. 동시에 여러 명이 획득할 수는 없습니다.
4. **운반:** 소지자는 이동과 전투를 할 수 있습니다. 질주·조준·공격에는 기존 노출 규칙이 적용됩니다.
5. **분실과 탈취:** 소지자가 사망하면 현장에 물건을 떨어뜨립니다. 다른 생존자가 획득해 이어서 운반할 수 있습니다.
6. **전달:** 목적지에서 전달 상호작용을 완료한 플레이어가 즉시 승리합니다.

획득·전달에 필요한 시간은 아직 미정입니다. 전달 중에는 이동할 수 없으며 피해를 받으면 진행을 취소하는 안으로 시작합니다. 취소된 경우 진행도는 초기화하고 물건은 계속 소지합니다.

### 운반자 정보와 외형

첫 테스트에서는 운반자의 이름이나 실시간 위치를 전체 공개하지 않는 안을 사용합니다. 목표를 향한 움직임으로 운반자를 추정하게 하기 위해서입니다.

다만 물건을 손에 드는 연출, 소지 전용 자세, 획득·분실 알림 범위는 미정입니다. 멀리서도 소지자가 확정되면 위장이 약해질 수 있고, 단서가 지나치게 없으면 경쟁이 어려워질 수 있습니다.

### 해결됐다고 가정하지 않을 문제

목적지를 무작위로 정하더라도 해당 라운드 안에서는 캠핑이 가능합니다. 복수 접근 경로 역시 캠핑을 완전히 막는 조건은 아닙니다.

실제 테스트에서 운반자와 대기자의 승률, 이동 위험, 목적지 방해 빈도를 비교합니다. 물건 운반이 기존 헬리콥터 캠핑 문제를 자동으로 해결한다고 보지 않습니다.

## 8. 모드별 검증

| 항목 | 1vs1 | 4인 개인전 |
| --- | --- | --- |
| 핵심 경험 | 한 상대를 관찰하고 속이며 접근 | 여러 상대의 노출과 교전을 이용 |
| 생존 승리 | 상대 사망 시 즉시 승리 | 마지막 한 명이 승리 |
| 운반 승리 | 상대보다 먼저 전달 | 나머지 생존자보다 먼저 전달 |
| 주요 위험 | 서로 행동하지 않는 교착, 첫 실수로 조기 종료 | 제삼자 개입, 운반 가로채기, 조기 사망 후 긴 대기 |
| 별도 조정 항목 | 맵 규모, NPC 수, 목표까지의 이동 시간 | 맵 규모, NPC 밀도, 교전 빈도, 관전 대기 시간 |

전투와 승리의 기본 규칙은 공유하되, 두 모드의 맵과 수치까지 동일하게 고정하지 않습니다. 3인 모드는 우선 지원 범위에 넣지 않습니다.

## 9. 라운드 진행과 종료

### 기본 진행

| 구간 | 플레이 목적 |
| --- | --- |
| 초반 | NPC 행동 파악, 수동 위장, 상대 관찰 및 기습 |
| 목표 활성화 이후 | 목표 접근으로 움직임 유도, 운반과 교전 사이 선택 |
| 후반 | 상대 추적, 목표 탈취, 전달 방해 또는 최후 생존 |

v0.3의 헬리콥터 호출 시간표는 사용하지 않습니다. 목표 활성화 시점과 운반 소요 시간은 1vs1·4인 개인전에서 따로 검증합니다.

### 시간 제한과 안전 구역

약 6분을 목표 라운드 길이로 유지합니다. 초기 테스트에서는 6분까지 승리 조건을 충족하지 못하면 실험을 종료하고 무승부로 기록하는 안을 제안합니다. 정식 시간 초과 규칙은 아직 미정입니다.

안전 구역 축소와 서든데스는 첫 검증에 포함하지 않습니다. 운반 목표 도입 후에도 장기 대기나 교착이 반복되면 도입을 검토합니다. 이후 안전 구역을 추가할 경우 물건과 목적지가 접근 불가능해지지 않도록 연동 규칙이 필요합니다.

### 동시에 발생하는 결과

생존 판정, 전달 완료, 사망은 서버에서 일관된 순서로 처리하고 라운드 결과는 한 번만 확정해야 합니다. 같은 판정 시점에 전원이 사망하면 무승부로 처리하는 안을 제안합니다.

전달 완료와 소지자 사망이 겹친 경우의 우선순위, 접속 종료에 따른 몰수패·라운드 취소 규칙은 구현 전 결정해야 합니다.

## 10. 플레이 상황 예시

### A. 직접 움직이며 접근

플레이어 A는 한 좀비가 자신의 이동 방향을 반복해서 따라오는 것을 보고 상대를 의심합니다. 바로 공격하지 않고 다른 좀비와 비슷한 속도로 걷다가 돌아서 상대 뒤에 접근합니다.

후방 타격에 성공하면 상대를 처치하지만, 공격 소리를 들은 좀비는 해당 위치를 조사하고 장면을 본 좀비는 반응합니다. A는 공격 이후의 이동 경로도 준비해야 합니다.

### B. 오인 공격 후 물러나기

플레이어 B는 NPC를 상대라고 오인해 뒤에서 공격합니다. NPC는 즉사하고 B의 경계가 한 단계 올라갑니다. 가까운 좀비는 공격 위치로 조사하러 옵니다.

B는 즉시 추격받지 않았더라도 연속 공격을 피하고 자리를 벗어납니다. 충분히 숨으면 경계가 감소하지만, 반복 공격으로 직접 발각되면 추격과 수색에서 벗어나야 합니다.

### C. 운반과 매복

플레이어 C가 물건을 확보하고 목적지로 이동합니다. 빠르게 질주하면 좀비에게 노출될 수 있어 평상시 보행으로 운반합니다.

플레이어 D는 목적지 방향으로 움직이는 대상을 의심해 접근합니다. C는 계속 위장하며 전달할지, 뒤따르는 D를 먼저 상대할지 선택합니다. C가 사망하면 D가 물건을 가져갈 수 있지만, 4인전에서는 다른 생존자도 그 상황을 이용할 수 있습니다.

## 11. 단계별 개발 범위

아래 항목은 개발 계획이며 구현 완료 목록이 아닙니다.

### 1단계: 위장과 근접 전투 검증

- 작은 맵 하나
- 1vs1 및 4인 개인전의 기본 세션
- NPC 배회와 플레이어 수동 이동
- 외형과 명중 전 UI를 통한 즉각적인 정체 식별 방지
- 동일 모션의 일반 근접 공격 및 후방 즉사
- 오인 공격 경계 누적, 조사, 추격, 수색, 재은신
- 사망 및 최후 생존 승패 처리
- 4인 테스트에서 사망 후 상태 확인을 위한 최소 관전

이 단계에서는 권총, 운반 퀘스트, 안전 구역을 추가하지 않습니다. 상대를 의심하고 접근하는 과정이 실제로 성립하는지 먼저 확인합니다.

### 2단계: 권총과 운반 승리 검증

- 권총 공격, 탄약·재장전 규칙, 총성 반응
- 무작위 후보 기반 물건·목적지 선정
- 획득, 운반, 사망 시 드롭, 탈취, 전달 완료
- 생존 승리와 운반 승리 통합
- 모드별 NPC 수, 맵 규모, 목표 활성화 시점 조정

### 3단계: 검증 결과에 따른 보완

- 장기 교착이 남으면 안전 구역 또는 다른 종료 압박 검토
- 후방 즉사와 카메라·회전 규칙 조정
- 공격 판정 지연에 따른 불일치 개선
- 관전과 재경기 흐름 보완

네트워크 동기화와 서버 판정은 각 단계의 기능에 포함합니다. 로컬 기능을 전부 만든 뒤 마지막에 붙이는 별도 작업으로 취급하지 않습니다.

## 12. 구현 판단 원칙

공격 명중, 후방 여부, 피해, 경계 누적, 물건 소유권, 전달 완료와 승패는 서버 기준으로 처리합니다. 공격 방향 계산식이 단순하다는 이유로 전체 멀티플레이 구현 난이도가 낮다고 평가하지 않습니다.

초기에는 서버 타격 시점의 위치와 회전으로 판정하고, 실제 네트워크 환경에서 사용자가 납득할 수 있는지 확인합니다. 위치 이력 보정 등은 불일치의 원인과 빈도를 확인한 뒤 검토합니다.

좀비 AI는 평상시 배회, 소음 조사, 직접 발각한 대상 추격, 마지막 위치 수색, 공격 및 복귀를 구분합니다. 전투·운반·승패가 경쟁하는 상황에서도 결과가 중복되지 않도록 처리해야 합니다.

현재 저장소의 구현 상태를 근거로 산정한 일정이나 난이도는 아닙니다. 본 문서는 기획 규칙과 검증 순서를 정리한 자료입니다.

## 13. 플레이테스트 기준

| 확인할 질문 | 관찰·기록할 내용 |
| --- | --- |
| 무엇을 보고 사람이라고 의심했는가? | 이동, 회전, 추적, 목표 반응 등 실제 근거 |
| NPC처럼 행동할 수 있었는가? | 위장 조작의 어려움과 너무 쉽게 들키는 행동 |
| 후방 즉사를 납득했는가? | 몸 방향, 카메라 시야, 공격 시점, 네트워크 불일치 |
| 오인 공격을 정체 확인용으로 남발했는가? | NPC 공격 횟수, 반복 공격 이후 행동, 경계의 실효성 |
| 첫 실수 후 회복할 수 있었는가? | 추격 전환 빈도, 재은신 가능 여부, 억울한 발각 |
| 무리 안에서 공격할 이유가 있었는가? | 무리 내부와 외곽의 교전 빈도 및 결과 |
| 직접 운반하는 것이 유리한가? | 최초 획득자·운반자·최종 승자, 운반 중 사망 |
| 목적지 대기가 지나치게 유리한가? | 캠핑 위치, 방해 횟수, 경로 선택과 탈취 결과 |
| 두 승리 조건이 모두 기능하는가? | 생존 승리·운반 승리·무승부의 발생 비율 |
| 모드별 라운드가 적절한가? | 종료 시간, 아무도 행동하지 않은 구간, 관전 대기 |

첫 테스트에서 임의의 승률이나 비율을 정답으로 고정하지 않습니다. 플레이 이유와 실패 원인을 기록한 뒤 수치와 규칙을 조정합니다.
